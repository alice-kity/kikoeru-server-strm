# 许可状态说明

截至 `0.1.1`，本仓库没有在根目录提供一个已核实的项目许可证；本文件不授予、也
不推断任何许可证。维护者需要在确认项目自有文件、上游镜像、复制的 overlay 代码
和依赖的分发条件后，单独决定是否添加根目录 `LICENSE` 以及对应的版权声明。

本项目当前 Dockerfile 基于 `number17/kikoeru` `0.6.17` 镜像构建。上游代码、镜像
内置文件和 npm 依赖的许可与本仓库文档是不同层次的事项，应以其随附的 LICENSE、
NOTICE 或发行说明为准；不能因为上游或依赖看起来使用某种常见许可证，就替本项目
作出同样的许可选择。

在许可证明确前：

- 不要把本仓库标注为 MIT、Apache-2.0、GPL 或其他具体许可证；
- 不要从生产镜像中删除上游版权/许可文件；
- 对外分发前先完成版权归属、上游通知和依赖清单审查；
- 问题报告和文档不要包含管理员密码、JWT、私人 Helper 地址或带签名的 CDN URL。
